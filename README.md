# Developer Productivity Agent

A smart exploration engine designed to help engineers navigate and understand large, unfamiliar codebases quickly without exceeding AI context windows.

## 🛠️ Key Components
* **Code Discovery Tools**: Built-in Grep and Glob utilities to find target code files and structural logical strings.
* **Persistent Scratchpad**: A dedicated tracking file where code exploration insights are preserved across long sessions.
* **Deep-Dive Explorer Subagent**: A delegated secondary specialist agent called by the coordinator to analyze specific complex blocks.
* **Current Status**: Complete exploration framework operational with live persistent scratchpad hooks.
